Chinmay Raul - Personal Website

A personal website built to tell the story behind my career rather than simply list it.

Instead of another online résumé, this project is an attempt to document the journey that took me from Mechanical Engineering to Manufacturing, Lean, Enterprise SaaS, ERP and AI. The goal is to explain not just where I worked, but how each chapter changed the way I think.

⸻

Philosophy
This website tries to answer a different question:

How did those experiences shape the person behind the résumé?

Every page is written as a chapter rather than a job description.

Design Philosophy

The website intentionally avoids traditional portfolio conventions.

There are:

* No timelines
* No long lists of achievements
* No corporate buzzwords
* No résumé copied onto a webpage

Instead, the site follows a storytelling approach.

Each chapter should feel like reading a chapter from a book.

⸻

Images

The website will not rely heavily on photographs.

Instead it will use artifacts.

Examples include:

* Internship offer letters
* Certificates
* Engineering notebooks
* CAD drawings
* Workshop sketches
* Project reports
* Competition certificates
* ID cards
* Presentation slides

Artifacts feel more authentic than posed photographs and better support the narrative.
